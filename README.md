# 地图标记工具 - 多人共享版

## 功能特点

✅ **多人共享** - 所有用户共享同一份标记数据，实时同步
✅ **地址搜索** - 支持搜索地址并快速添加标记
✅ **点击地图添加** - 直接在地图上点击添加标记
✅ **历史记录** - 标记变更自动保存历史，可追溯
✅ **导航跳转** - 一键跳转到高德地图导航

## 快速启动

### 1. 安装依赖
```bash
cd D:\workbuddy\map-server
npm install
```

### 2. 启动服务器
```bash
npm start
```

### 3. 访问应用
服务器启动后，在浏览器打开：
- **本机访问**: http://localhost:3000
- **局域网访问**: http://你的IP地址:3000

> 同一局域网内的其他设备都可以访问并共享标记数据

## 使用方法

### 添加标记
1. 在地图上点击要标记的位置
2. 填写标记名称
3. 选择分类（常用/家庭/工作等）
4. 可选填写备注信息
5. 点击「保存标记」

### 编辑标记
1. 在左侧列表找到要编辑的标记
2. 点击「✏️ 编辑」按钮
3. 修改信息后保存
4. 旧数据会自动保存到历史记录

### 查看历史
1. 点击「📜 历史」按钮
2. 可以看到当前位置和历史变更记录

### 删除标记
1. 点击「🗑️ 删除」按钮
2. 确认后删除

## 多人使用说明

### 同一局域网（推荐）
1. 启动服务器后，其他用户访问 `http://你的IP:3000`
2. 所有用户的操作会自动同步
3. 建议定期点击「🔄 刷新数据」按钮查看最新数据

### 远程访问
如果需要远程访问（不同网络），需要：
1. 配置路由器端口转发（端口：3000）
2. 或使用内网穿透工具（如 ngrok）
3. 或部署到云服务器

## 数据存储

数据保存在 `markers.json` 文件中（与 server.js 同目录）

## 文件结构
```
map-server/
├── server.js      # 后端服务器
├── index.html     # 前端页面
├── package.json   # 依赖配置
└── markers.json   # 标记数据（自动生成）
```

## 技术栈

- **前端**: HTML + CSS + JavaScript
- **地图**: 高德地图 JavaScript API
- **后端**: Node.js + Express
- **存储**: JSON 文件

## 故障排除

### 无法访问
- 检查服务器是否运行（命令行窗口是否打开）
- 检查防火墙是否阻止了 3000 端口

### 数据不同步
- 点击「🔄 刷新数据」按钮
- 检查网络连接

### 地图加载失败
- 检查高德地图 API Key 是否有效
- 检查网络连接
